How do I get my .ics file?
  1. Apple Calendar (Mac): File → Export → Export… saves an .ics.
  2. Google Calendar: Settings → Import & export → Export (downloads a .zip; unzip to get .ics).
  3. Outlook: File → Save Calendar, or export the calendar as iCalendar (.ics).
